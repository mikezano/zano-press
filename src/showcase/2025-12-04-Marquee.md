```html
<div class="marquee">

    <div class="light"></div>

  </div>

    <div class="light"></div>
    <!--3x light-->
  </div>
  <div class="corner bottom-left"></div>
  <div class="lights-bottom">
    <div class="light"></div>
    <!--9x light-->
  </div>

```

- `corner` - the inward curved corner to give the marquee some elegance 💅🏼
- `light` - light bulb elements surrounding the marquee which are aligned with flex properties in horizontal/vertical manners
- `content` - The main area making the announcement (usually announcing a play/movie 🎥)

Let's look at the CSS structure for these different pieces

## CSS on the corners

In order to get an inward-looking swoop on the marquee corners we need to transform the `div` element shape into a circle and control from where the center starts. For that purpose the `clip-path` property which has the following value syntax:

`circle(<radius> at <x> <y>);`

The `at x, y` helps control the starting point. With a value of `at 0% 0%` we would essentially start a circle from the top-left corner its selected html element. Example:

```css
.corner.top-left {
  clip-path: circle(100% at 0% 0%);
}
```

Following that pattern, for the other corners we would have:

- top-right = 100% 0%
- bottom-left = 0% 100%
- bottom-right = 100% 100%

## CSS for the lights 💡

We want to create movement in the lights to simulate travel in a clock-wise the way they typically move on a marquee. In order to make it 'even' we need the amount of lights on each side to be of a specified multiple with # of lights on top=bottom and left=right. Doing so will create 'smooth' movement. In this case we use a multiple of 3. The top/bottom have 9 lights and the left/right side have 3.

</div>

Note the numbering which represents how we want them to render as they appear on the screen (This will help with animation explained below). We need the top/bottom row of lights need to be aligned in a horizontal manner with `flex-alignment: flex-row` and the bottom row to be laid out in a `flex-direction: row-reverse` to acheive the clock-wise arrangement.

```css
.lights-bottom {
  flex-alignment: row-reverse;
}
```

The left/right lights also need some flex treatment since items need to be vertical with the left lights also keeping rendering in a clockwise manner from bottom -> top. Here's what our CSS needs

```css
.lights-left,
.lights-right {
  flex-direction: column;
}
.lights-left {
  flex-alignment: column-reverse;
}
```

With that in place we are ready for some animtation.

Top lights = flex rows = horizontal alighment
left/right lights = flex column = vertial alignment

.lights-top .light:nth-child(3n),
.lights-bottom .light:nth-child(3n),
.lights-left .light:nth-child(3n),
.lights-right .light:nth-child(3n) {
animation: pulse 0.6s linear infinite;
}

## Animation

We only need one animation to happen for each light which we name 'pulse'. As with the number of lights we also keep the timing of to a multiple of 3 so we can stagger a delay for the other lights and keep things smooth as they go on/off

```css

@keyframes pulse {
    0% {background-color: hsla(48, 100%, 75%, 1);} /* light bulb on */
   50% {background-color: hsla(48, 50%, 35%, 0.5);} /* light bulb off */
}
</style>

```

We need a group of selectors to work with selecting things 3 at a time. In the below we look at the `.lights-top` row and what happens with the first three lights. With the selector `3n` we are selecting the first light and immediately run the pulse animation that turns it on. The second rule with a `3n+1` selects the next light which ads a delay `0.2s` followed by the third light selected by `3n+2` and a further delay `0.4s` to make 'motion' happen

```css
.lights-top .light:nth-child(3n) {
  animation: pulse 0.6s linear infinite;
}
.lights-top .light:nth-child(3n + 1) {
  animation: pulse 0.6s 0.2s linear infinite;
}
.lights-top .light:nth-child(3n + 2) {
  animation: pulse 0.6s 0.4s linear infinite;
}
```
