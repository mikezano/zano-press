Let's look at the CSS structure for these differen pieces

## CSS'ing the corners

In order to get an inward-looking swoop on the marquee corners we need to transform the div element shape into a circle and control from where the center starts. For that purpose the `clip-path` allows specifying shapes and has the `at X, Y` syntax to help control the starting point. With a value of `at 0% 0%` we would essentially start a circle from the top-left corner of the cell. Example:

```css
.corner.top-left {
  clip-path: circle(100% at 0% 0%);
}
```

Following that pattern, for the other corners we have.

- top-right = 100% 0%
- bottom-left = 0% 100%
- bottom-right = 100% 100%

## CSS lights

We want to create movement in the lights to simulate travel in a clock-wise the way they typically do on a marquee. In order to make it 'even' we need the amount of lights on each side to be of any multiple number with # of lights on top=bottom and left=right. Doing so will create 'smooth' movement. In this case we use a multiple of 3. The top/bottom have 9 lights and the left/right side have 3.

We need to also consider that the top/bottom row of lights need to be aligned in a horizontal manner with `flex-alignment: flex-row` (which is the default). If we thing of the way the these lights are rendered we need the bottom ones to be considered aas starting from the right to left to keep the clockwise paradigm for that purpose we need, to apply the following

```css
.lights-bottom {
  flex-alignment: row-reverse;
}
```

The left/right lights also need some flex treatment since items need to be vertical with the left lights also keeping rendering in a clockwise manner from bottom -> top. Here's what our CSS needs

```css
.lights-left,
.lights-right {
  flex-direction: column;
}
.lights-left {
  flex-alignment: column-reverse;
}
```

With that in place we are ready for some animtation.

Top lights = flex rows = horizontal alighment
left/right lights = flex column = vertial alignment

.lights-top .light:nth-child(3n),
.lights-bottom .light:nth-child(3n),
.lights-left .light:nth-child(3n),
.lights-right .light:nth-child(3n) {
animation: pulse 0.6s linear infinite;
}
