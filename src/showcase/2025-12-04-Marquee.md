## HTML makeup

```html
<div class="marquee">
  <div class="corner top-left"></div>
  <div class="lights-top">
    <div class="light"></div>
    <!--8x light-->
  </div>
  <div class="corner top-right"></div>
  <div class="lights-left">
    <div class="light"></div>
    <!--2x light-->
  </div>
  <div class="marquee-content">
    <p>🎼CSS: The Musical 🎺</p>
  </div>
  <div class="lights-right">
    <div class="light"></div>
    <!--2x light-->
  </div>
  <div class="corner bottom-left"></div>
  <div class="lights-bottom">
    <div class="light"></div>
    <!--8x light-->
  </div>
  <div class="corner bottom-right"></div>
</div>
```

At the foundation of this is a 3x3 CSS grid structure with cells depected as down bellow:

<table>

- `.corner` - essentially an inward curved corner to give the marquee some elegance 💅🏼
- `.light` - lights surrounding the marquee which are aligned with flex properties in horizontal/vertical manners
- `.content` - The main area making the announcement

Let's look at the CSS structure for these differen pieces

## CSS'ing the corners

In order to get an inward-looking swoop on the marquee corners we need to transform the div element shape into a circle and control from where the center starts. For that purpose the `clip-path` allows specifying shapes and has the `at X, Y` syntax to help control the starting point. With a value of `at 0% 0%` we would essentially start a circle from the top-left corner of the cell. Example:

```css
.corner.top-left {
  clip-path: circle(100% at 0% 0%);
}
```

Following that pattern, for the other corners we have.

- top-right = 100% 0%
- bottom-left = 0% 100%
- bottom-right = 100% 100%
